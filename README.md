# מנסח ברכות - מערכת מוכנה לשחרור לציבור

מבנה: דף סטטי (`public/index.html`) + שרת קטן (`app/api/generate`) שמסתיר את מפתח ה-API ומגביל שימוש.

## איך זה עובד
- המשתמש ממלא טופס בדפדפן.
- הדפדפן בונה את הפרומפט (כמו קודם) ושולח אותו ל-`/api/generate` באתר **שלך** - לא לגוגל ישירות.
- השרת שלך בודק הגבלת שימוש יומית, ורק אז שולח בקשה ל-Gemini באמצעות מפתח שמור בסביבת השרת (לא חשוף לאף אחד).

## שלב 1 - הכנת חשבונות (חד פעמי, ~10 דקות)
1. **GitHub** - הרשמה חינמית ב-github.com. תעלה לשם את תיקיית הפרויקט הזו (repo חדש).
2. **Google AI Studio** - כנס ל-https://aistudio.google.com/apikey, צור מפתח Gemini API חינמי, שמור אותו בצד.
3. **Vercel** - הרשמה חינמית ב-vercel.com **דרך חשבון ה-GitHub שלך** (Continue with GitHub) - כך זה מתחבר אוטומטית.

## שלב 2 - העלאה ל-GitHub
- ב-GitHub: New Repository → תן שם (למשל `nussach-berachot`) → Create.
- העלה את כל תוכן התיקייה הזו (או, אם נוח לך, תגיד לי ואני אכין לך גם את פקודות ה-git המדויקות).

## שלב 3 - חיבור ל-Vercel ופריסה (Deploy)
1. ב-Vercel: **Add New → Project**.
2. בחר את ה-repo שהעלית.
3. לפני שלוחצים Deploy - תחת **Environment Variables** הוסף:
   - `GEMINI_API_KEY` = המפתח שקיבלת בשלב 1
   - `DAILY_FREE_LIMIT` = `10` (או כל מספר אחר - זכור: Gemini Flash החינמי נותן כ-1,500 בקשות ליום *לכל האתר*, אז 10 למשתמש מספיקים ל-~150 משתמשים ביום)
4. לחץ **Deploy**. אחרי דקה תקבל כתובת ציבורית חיה כמו `nussach-berachot.vercel.app`.

## שלב 4 (מומלץ לפני תנועה אמיתית) - הגבלת שימוש אמיתית
כרגע ההגבלה היומית נשמרת בזיכרון של השרת - זה עובד לבדיקות, אבל ב-Vercel האמיתי יש כמה שרתים מקבילים, אז ההגבלה עלולה "להתאפס" בין בקשות. כדי שההגבלה תהיה אמיתית:
1. הירשם בחינם ב-https://upstash.com → צור מסד Redis חדש.
2. העתק את ה-`UPSTASH_REDIS_REST_URL` וה-`UPSTASH_REDIS_REST_TOKEN` שהוא נותן לך.
3. הוסף אותם כ-Environment Variables ב-Vercel (כמו בשלב 3) ולחץ Redeploy.

## שלב 5 - דומיין אישי (רשות)
ב-Vercel Project Settings → Domains אפשר לחבר דומיין משלך במקום `vercel.app`.

## מה עוד שווה להוסיף בהמשך (לא דחוף)
- **דרגות תשלום** - אם המכסה החינמית לא מספיקה למישהו, כרגע הפתרון הוא שיזין מפתח Gemini אישי משלו (חינמי גם הוא). בהמשך, אם תרצה מודל עסקי אמיתי, אפשר להוסיף Stripe ותשלום עבור מכסה מוגדלת/מודל טוב יותר - זה שלב נפרד ונדבר עליו כשתגיע לשם.
- **לוג הערות תיקון** - כדי לאסוף נתונים לשיפור עתידי של הפרומפט, כפי שדיברנו.
- **החלפת מודל** - כרגע `GEMINI_MODEL` מוגדר בקובץ `app/api/generate/route.js`. אם תרצה לנסות מודל אחר (או ספק אחר), משנים שורה אחת שם.
